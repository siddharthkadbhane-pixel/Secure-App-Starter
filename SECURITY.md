# Security policy

## Reporting a vulnerability

Do not open a public issue containing exploitable details, credentials, or personal data. Report suspected vulnerabilities privately to the repository owner using the configured private reporting channel.

Include the affected area, impact, and safe reproduction steps. Do not include real user data or live secrets.

## Response expectations

The repository owner should acknowledge reports, assess severity and affected versions, coordinate a fix, and communicate a disclosure timeline with the reporter. Do not publish a fix or exploit details before affected users have a reasonable mitigation path.

## Scope

This policy applies to this repository and applications built from it only where the owner has explicitly adopted it. It does not promise a security response for third-party deployments.
